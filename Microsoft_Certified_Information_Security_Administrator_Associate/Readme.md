## Beschreibung:
Diese Prüfungsvorbereitung dient der Vorbereitung auf die Prüfung SC-401: Administering Information Security in Microsoft 365. In diesem umfassenden Kurs werden die Teilnehmenden auf die Zertifizierung zum "Microsoft Certified: Information Security Administrator Associate" vorbereitet. Sie lernen, wie vertrauliche Informationen in Microsoft 365 mit Microsoft Purview und zugehörigen Sicherheitsdiensten klassifiziert, geschützt, überwacht und verwaltet werden.

Der Kurs behandelt zentrale Themen wie Informationsschutz, Sensitivity Labels, Data Loss Prevention (DLP), Endpoint DLP, Aufbewahrung und Datenlebenszyklusverwaltung. Zusätzlich werden Insider Risk Management, Audit, Aktivitätenanalyse, Warnungen, eDiscovery sowie der Schutz von Daten in Umgebungen mit KI-Diensten behandelt. Der Schwerpunkt liegt auf praxisnahen Szenarien, damit die Teilnehmenden technische Kontrollen mit organisatorischen Sicherheits-, Governance- und Compliance-Anforderungen verbinden können.

## Praxisbeispiel: Eine E-Mail. Fünf Sicherheitsschichten. Vier davon haben nur zugeschaut.
Ein Mitarbeiter sendet Kreditkartendaten an ein externes Postfach. So reagiert der Microsoft Security Stack:

- 🔐 Microsoft Entra ID: gültiger Benutzer, MFA bestanden - Zugriff gewährt
- 💻 Endpoint Detection and Response (EDR): kein bösartiger Prozess - nichts zu erkennen
- 🛡️ Anti-Malware: Anhang ist sauber - Zustellung möglich
- 🌐 Netzwerk: normaler HTTPS-Verkehr - erlaubt

Jede einzelne Kontrolle hat ihren Job korrekt gemacht. Und trotzdem hätten sensible Daten das Unternehmen verlassen können.

⛔ Microsoft Purview Data Loss Prevention (DLP): sensibler Inhalt erkannt, Versand blockiert und Vorfall protokolliert.

## Bewertete Qualifikationen:
- Implementieren von Informationsschutz

- Implementieren von Data Loss Prevention und Aufbewahrung

- Verwalten von Risiken, Warnungen und Aktivitäten

## 4-Nachmittage Kursprogramm:

### Nachmittag 1: Informationsschutz und Datenklassifizierung
- Rollenbild des Information Security Administrators
- Überblick über Microsoft Purview und relevante Microsoft 365 Sicherheitsdienste
- Sensible Informationstypen, benutzerdefinierte Klassifizierungen und Exact Data Match (EDM)
- Dokumentfingerprinting, trainierbare Klassifizierer und OCR-Unterstützung
- Auswertung von Klassifizierungs- und Label-Aktivitäten mit Data Explorer und Content Explorer

### Nachmittag 2: Sensitivity Labels und Verschlüsselung
- Planung und Verwaltung von Sensitivity Labels in Microsoft Purview
- Label-Richtlinien, automatische Bezeichnung und Schutzkonfigurationen
- Sensitivity Labels für Dateien, E-Mails, Teams, Microsoft 365 Gruppen, SharePoint Sites und Power BI
- Microsoft Purview Information Protection Client und Scanner
- Microsoft Purview Message Encryption und Advanced Message Encryption

### Nachmittag 3: Data Loss Prevention und Aufbewahrung
- Planung, Erstellung und Verwaltung von DLP-Richtlinien
- Richtlinienpriorität, Regeln, Berechtigungen und Adaptive Protection
- Endpoint DLP, Gerätevoraussetzungen, erweiterte Regeln und Aktivitätsüberwachung
- DLP-Szenarien mit Microsoft Defender for Cloud Apps
- Retention Labels, Retention Policies, adaptive Richtlinienbereiche und Wiederherstellung aufbewahrter Inhalte

### Nachmittag 4: Risiken, Warnungen, Aktivitäten und Prüfungsvorbereitung
- Microsoft Purview Insider Risk Management und Adaptive Protection
- Audit, Activity Explorer, Warnungen und Untersuchungen im Microsoft Purview Portal
- Reaktion auf DLP-, Insider-Risk- und Defender-for-Cloud-Apps-Warnungen
- eDiscovery-Grundlagen für Informationssicherheits-Szenarien
- Schutz von Daten, die durch KI-Dienste verwendet werden, inklusive Data Security Posture Management (DSPM) for AI
- Prüfungsvorbereitung, typische Fragestellungen und Empfehlungen für das Selbststudium

Der Kurs richtet sich an IT-Fachkräfte, Security Administratoren, Compliance-Verantwortliche und Governance-Spezialistinnen und -Spezialisten, die Informationsschutz und Risikominimierung in Microsoft 365 planen, implementieren und verwalten möchten.
