## Beschreibung:
Im "Microsoft Certified: Windows Server Hybrid Administrator Associate Workshop" lernen Teilnehmerinnen und Teilnehmer, wie Windows Server Workloads lokal, in der Cloud und in hybriden Umgebungen bereitgestellt, implementiert, verwaltet, abgesichert, überwacht und bei Problemen analysiert werden. Der Kurs orientiert sich an den Kompetenzbereichen der Zertifizierung Microsoft Certified: Windows Server Hybrid Administrator Associate und behandelt zentrale Themen der Prüfung AZ-802: Verwalten von Windows Server.

Der Workshop verbindet klassische Windows Server Administration mit modernen Hybrid-Szenarien. Dazu gehören Active Directory Domain Services, Windows Server Instanzen und Workloads, Hyper-V und Azure virtuelle Computer, lokale und hybride Netzwerkinfrastrukturen, Speicher- und Dateidienste, Windows Server Sicherheit, Azure Arc, Azure Update Manager, Azure Monitor, Windows Admin Center, PowerShell und Microsoft Defender for Cloud. Ziel ist es, bestehende Windows Server Umgebungen sicher zu betreiben und sinnvoll mit Microsoft Cloud-Diensten zu erweitern.

## Hauptthemen:

**Modul 1: Bereitstellen und Verwalten von Active Directory Domain Services (AD DS)**  

- Überblick über die Rolle Windows Server Hybrid Administrator Associate
- Einordnung der Prüfung AZ-802: Verwalten von Windows Server
- Überblick über die AZ-802 Skillbereiche und Prüfungsanforderungen
- Bereitstellen und Verwalten von Active Directory Domain Services
- Domänencontroller, FSMO-Rollen, Sites und Replikation
- Verwalten von Benutzern, Gruppen, Computern und Organisationseinheiten
- Gruppenrichtlinien planen, konfigurieren und anwenden
- Absichern und Betreiben von AD DS in lokalen und Cloud-Szenarien


**Modul 2: Verwalten von Windows Server Instanzen und Workloads in einer Hybridumgebung**  

- Windows Server Editionen, Installationsoptionen und Verwaltungswerkzeuge
- Verwalten von Windows Server mit Server Manager, Windows Admin Center und PowerShell
- Einführung in Azure Arc für Server
- Onboarding von Windows Servern in Azure Arc
- Verwalten von Servern mit Azure Policy, Tags und Extensions
- Azure Update Manager für hybride Serverumgebungen
- Automatisieren wiederkehrender Administrationsaufgaben mit PowerShell
- Planen von lokalen, Cloud- und Hybrid-Szenarien für Windows Server Workloads


**Modul 3: Verwalten virtueller Computer**  

- Einführung in Hyper-V, virtuelle Switches und virtuelle Maschinen
- Erstellen, Konfigurieren und Verwalten von Hyper-V VMs
- Verwalten von Hyper-V mit Windows Admin Center und PowerShell
- Verwalten von Azure IaaS VMs mit Windows Server
- Konfigurieren von VM-Speicher, Netzwerk und Verfügbarkeit
- Absichern und Aktualisieren virtueller Windows Server Systeme
- Grundlagen zur Fehlerbehebung von Virtualisierungsumgebungen


**Modul 4: Implementieren und Verwalten einer lokalen und hybriden Netzwerkinfrastruktur**  

- Grundlegende Netzwerk-, DNS- und Namensauflösungskonzepte
- Bereitstellen und Verwalten von DNS, DHCP und IPAM
- Netzwerkdienste, Routing, Remotezugriff und VPN-Szenarien
- Implementieren und Verwalten lokaler und hybrider Netzwerk-Infrastrukturen
- Azure Netzwerkgrundlagen für Windows Server Workloads
- Namensauflösung und Konnektivität zwischen lokalen Netzwerken und Azure
- Troubleshooting von Netzwerk- und Serverdiensten


**Modul 5: Verwalten von Speicher- und Dateidiensten**  

- Planen und Verwalten von Windows Server Storage
- Storage Spaces, Storage Spaces Direct und Datenträgerverwaltung
- Konfigurieren von iSCSI und SMB-basierten Szenarien
- Planen und Konfigurieren von Dateidiensten und Berechtigungen
- NTFS-, Freigabe- und Access-Based Enumeration Konzepte
- Konfigurieren von DFS Namespaces und DFS Replication
- Azure File Sync für hybride Dateidienste


**Modul 6: Sichern der Windows Server Infrastruktur**  

- Windows Server Security Baselines und Hardening
- Verwalten privilegierter Zugriffe und administrativer Konten
- Absichern von Active Directory und Domänencontrollern
- Microsoft Defender for Cloud für Windows Server
- Windows Defender, Firewall und Credential Guard Grundlagen
- Just Enough Administration und PowerShell Remoting Security
- Sicherheitsrelevante Überlegungen für Windows Admin Center, PowerShell und Azure Arc


**Modul 7: Überwachen und Beheben von Windows Server Umgebungen**  

- Azure Monitor, Log Analytics und Change Tracking
- Überwachen von Leistung, Ereignissen und Systemzustand
- Überwachen und Beheben von Windows Server Umgebungen
- Fehlerbehebung bei AD DS, Netzwerk, Storage, Hyper-V und Azure Arc
- Praxisnahe Troubleshooting-Szenarien aus hybriden Umgebungen
- Wiederholung der wichtigsten AZ-802 Themenbereiche
- Empfehlungen für die Prüfungsvorbereitung und weiterführende Lernpfade

## Voraussetzungen:
Um an diesem Workshop teilzunehmen, sollten Sie über grundlegende IT-Kenntnisse verfügen und Erfahrung mit Windows Server oder Windows Client Administration mitbringen.

Weitere Voraussetzungen sind:  
		- Grundlegende Kenntnisse von Windows Server und Active Directory  
		- Grundlegende Kenntnisse von Netzwerken, DNS, DHCP und TCP/IP  
		- Erste Erfahrung mit PowerShell  
		- Grundlegendes Verständnis von Microsoft Azure und Microsoft Entra ID  

**Empfehlung:**  
Damit Sie dem Workshop bestens folgen können, empfehlen wir eine eigene Testumgebung mit mindestens einem Windows Server und einem Windows Client. Für die Hybrid-Szenarien ist ein Azure Test- oder Trainingsabonnement hilfreich.

## Zielgruppe:
Dieser Workshop richtet sich an IT-Profis, Systemadministratorinnen und Systemadministratoren, Cloud Engineers und Entscheidungsträger:Innen, die Windows Server Umgebungen lokal und hybrid mit Microsoft Azure verwalten möchten.

Nach Abschluss des Workshops haben Sie ein solides Verständnis der Windows Server Hybrid Administration. Sie können AD DS bereitstellen und verwalten, Windows Server Instanzen und Workloads in hybriden Umgebungen betreiben, virtuelle Computer verwalten, lokale und hybride Netzwerke implementieren, Speicher- und Dateidienste konfigurieren, Windows Server Infrastrukturen absichern sowie Windows Server Umgebungen überwachen und bei Problemen analysieren.

## Hinweis:
Dieser Workshop ist praxisorientiert und bietet viele Übungen und Beispiele, um das Gelernte zu vertiefen. Die Inhalte unterstützen die Vorbereitung auf die Zertifizierung Microsoft Certified: Windows Server Hybrid Administrator Associate, ersetzen jedoch keine individuelle Prüfungsvorbereitung mit zusätzlicher Praxis und offiziellen Microsoft Learn Unterlagen.
